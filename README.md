# Palindrome
## Palindrome Checker

This project is a simple, browser-based tool for checking whether text reads the same forwards and backwards. It’s built as a single HTML page, so there’s no installation or setup required—open `index.html` in a browser to use it.

Type or paste a word, phrase, or sentence to see the result instantly. The checker ignores capitalization, spaces, and punctuation, and shows both the cleaned text and its reverse. Five example buttons let you try it out quickly.

### For the stretch part-
It also stretches to find the **longest whole word** in your input 

**First case- palindrome phrase with no palindromic word**
-For example,"Was it a car or a cat I saw?",  is a palindrome however it does not have any palindromic words.

**Second case- Not a palindrome phrase WITH palindromic word**
-An another example would be where a phrase is not a palindrome but contains a palindromic word,
  for example:"Wow, my racecar saw level noon.", is not a palindrome as a phrase but it contains a palindromic word -racecar
